Privacy

mask2ai exists to keep personal data off the wire. It has no wire of its own.

Last updated 30 September 2026.

What it reads

In Claude Code: the prompt you submit, the input and output of each tool call, and the text of each reply as it streams, all handed to it by Claude Code's hook system. In Chrome: the body of chat requests to claude.ai and chatgpt.com, files you upload on those sites, and the text rendered on those pages. Nothing else.

Within that, it looks for personal data: names, email addresses, phone numbers, national ID and social security numbers, dates of birth and street addresses, and payment data such as card numbers and IBANs. All of it is handled inside your browser tab or your Claude Code session. None of it is sold, shared, or used for anything except masking and restoring it.

What it stores

A map from placeholder to real value, so the values can be restored. In Claude Code it is a file under the plugin's data directory, one per session, mode 0600, deleted when the session ends. In Chrome it is in the tab's sessionStorage and is gone when the tab closes. There is no other state, no cache and no log.

What it sends

Nothing to mask2ai. There is no server, no account, no telemetry and no update check. The only traffic is the traffic you were already sending to Anthropic or OpenAI, with placeholders in place of the personal data that was recognised.

What still reaches the provider: placeholders, everything the patterns do not recognise, file paths, and your prompt once you resend it in masked form. Detection is pattern based; the docs list exactly what is and is not caught.

The code

About 500 lines of JavaScript and a 70-line Swift helper that reads text in images and PDFs on macOS, with no dependencies beyond Node.js and the operating system, MIT licensed, at github.com/serkankorkut/mask2ai. The repository ships a proof that captures every byte Claude Code sends and a headless check of the extension on both sites.

Contact

Questions about privacy: open an issue at github.com/serkankorkut/mask2ai/issues. mask2ai is not affiliated with OpenAI or Anthropic.
